# Praatbord

Een Nederlandse spraakcomputer voor jonge kinderen, als web-app voor de iPhone of iPad.

## Online zetten met GitHub Pages

1. Maak een gratis account op github.com en log in.
2. Klik rechtsboven op **+** en kies **New repository**. Noem hem `praatbord`, zet hem op **Public** en klik **Create repository**.
3. Klik op **uploading an existing file**. Sleep alle bestanden uit deze map erin: `index.html`, `sw.js`, `manifest.webmanifest`, `icon-180.png`, `icon-192.png`, `icon-512.png` en dit bestand. Klik **Commit changes**.
4. Ga naar **Settings**, dan **Pages**. Kies bij **Branch** voor `main` en de map `/ (root)`. Klik **Save**.
5. Wacht een paar minuten. Bovenaan de Pages-instellingen verschijnt het adres, iets als `https://jouwnaam.github.io/praatbord/`.

## Op de iPhone zetten

1. Open dat adres in **Safari**. Andere browsers kunnen op de iPhone geen app op het beginscherm zetten.
2. Tik op het deel-icoon en kies **Zet op beginscherm**.
3. Open Praatbord via het nieuwe icoon. Houd rechtsonder de ouderknop vast en vul de naam van je kind in.
4. Open de app één keer met internet. Daarna werkt hij ook zonder.

## Een nieuwe versie plaatsen

1. Upload de nieuwe `index.html` op dezelfde manier. GitHub vervangt de oude.
2. Open `sw.js` op GitHub, klik op het potloodje en maak van `praatbord-1` het volgende nummer, bijvoorbeeld `praatbord-2`. Klik **Commit changes**.
3. Open de app op de iPhone, sluit hem helemaal af en open hem opnieuw. Dan staat de nieuwe versie erop.

## Privacy

De pagina zelf staat openbaar online, maar er zit geen persoonlijke informatie in. De naam, eigen foto's, eigen woorden en wat het bord leert, worden alleen op de telefoon zelf bewaard. Verwijder je het icoon of de websitegegevens van Safari, dan ben je die kwijt.
